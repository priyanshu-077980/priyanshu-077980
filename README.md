> **PlantCare AI** is a production-grade agricultural diagnosis platform designed to detect and manage crop foliar diseases in real time.

- **🔬 67 Pathology Classes**: Multi-class CNN neural network diagnosing blight, rust, scab, and healthy states across major agricultural crops.
- **🤖 GenAI Agronomist**: Integrated local Ollama (llama3.2) chatbot offering contextual, organic, and chemical recovery advisory without data leakage.
- **⚡ Sub-Second Inference**: Clean REST endpoints serving instant softmax probability distributions and confidence scores.
- **📊 Modern Web Studio**: Built with React 19, Tailwind CSS, Recharts analytics, and local audit persistence.
